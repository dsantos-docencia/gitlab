# 🌱 Scripts da comunidade

Esta pasta é um **catálogo colaborativo**: scripts úteis enviados por pessoas da comunidade, curados e creditados.

> **Quer enviar o seu?** Abra uma issue pela trilha **"📜 Enviar um script para a comunidade"** ([nova issue](https://github.com/dsantos-docencia/gitlab/issues/new/choose)). A gente avalia, comenta e, se fizer sentido, inclui aqui com o seu crédito. *Não deixe o conhecimento morrer com você.*

## Como funciona a curadoria

1. Você envia o script (issue ou PR) e conta que problema ele resolve.
2. Revisamos juntos: clareza, segurança (sem efeitos destrutivos surpresa), e se ele passa no ShellCheck.
3. Ajustamos o que for preciso — sempre mantendo **seu crédito como autor**.
4. Entra aqui, com um cabeçalho padrão e uma linha no índice abaixo.

## Padrão de um script da comunidade

Cada script traz um cabeçalho assim:

```bash
#!/usr/bin/env bash
# ============================================================================
#  Script da comunidade · <nome>
#  Autoria: <Seu Nome> (@seu-usuario)
#  Curadoria: curso de GitHub do Prof. Daniel Santos
#  Licença: PolyForm Noncommercial 1.0.0 (uso não comercial) — veja /NOTICE.md
#  O que faz: <uma linha>
# ============================================================================
```
